달력 위젯 개인정보처리방침

시행일: 2026년 11월 26일

1. 읽는 정보

사용자가 구글 계정으로 로그인하고 허용하면, 달력 위젯은 그 계정의 캘린더 목록과 일정(제목, 시간, 장소, 메모)을 구글 캘린더 API로 읽습니다. 사용자가 위젯에서 일정을 추가하거나 고치거나 지우면 같은 API로 구글 캘린더에 반영합니다.

2. 정보를 쓰는 곳

읽은 일정은 사용자 PC의 위젯 화면에 보여 주는 데만 씁니다. 광고, 분석, 판매에 쓰지 않습니다.

3. 저장과 전송

  • 달력 위젯에는 운영 서버가 없습니다. 일정 정보는 사용자 PC와 구글 사이에서만 오가고, 개발자나 다른 누구에게도 보내지 않습니다.
  • 로그인 유지에 필요한 토큰은 사용자 PC 안에 윈도우 계정으로만 풀 수 있게 암호화해 저장합니다. 비밀번호는 저장하지 않습니다.
  • 일정 내용은 PC에 따로 저장하지 않고, 화면을 그릴 때마다 구글에서 새로 받아 옵니다.

4. 연결 끊기와 삭제

  • 위젯 메뉴의 "구글 계정 연결 끊기"를 누르면 PC에 저장된 토큰을 지웁니다.
  • 구글 계정의 서드파티 액세스 관리 화면에서 "달력 위젯"의 권한을 언제든 해제할 수 있습니다.
  • 프로그램을 제거하고 %APPDATA%\CalendarWidget 폴더를 지우면 PC에 남은 설정과 토큰이 모두 사라집니다.

5. 구글 API 서비스 사용자 데이터 정책

달력 위젯이 구글 API에서 받은 정보를 쓰고 다루는 방식은 제한적 사용(Limited Use) 요구 사항을 포함한 Google API Services User Data Policy를 따릅니다.

6. 바뀌는 경우

이 방침이 바뀌면 이 페이지에 고친 내용과 시행일을 올립니다.
